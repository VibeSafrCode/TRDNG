## Apple contract checked

Only official Apple sources were used, checked 2026-08-14:

- [TN3137: On Mac keychain APIs and implementations](https://developer.apple.com/documentation/Technotes/tn3137-on-mac-keychains):
  SecItem defaults to the file-based keychain on macOS; the data-protection
  keychain is selected explicitly and derives access groups from the host main
  executable's signing entitlements.
- [`kSecUseDataProtectionKeychain`](https://developer.apple.com/documentation/security/ksecusedataprotectionkeychain):
  Apple recommends setting it for iOS-like data-protection behavior.
- [`kSecAttrAccessible`](https://developer.apple.com/documentation/security/ksecattraccessible):
  on macOS this attribute applies only when data-protection or synchronization is
  enabled.
- [`errSecMissingEntitlement`](https://developer.apple.com/documentation/security/errsecmissingentitlement):
  identifies a missing required entitlement and Apple directs developers to
  inspect the built app's entitlements.
- [`errSecParam`](https://developer.apple.com/documentation/security/errsecparam):
  means one or more parameters are invalid.

No access group or data-protection attribute was added: the preceding evidence is
not enough to choose that product contract safely.

   an accessibility attribute that Apple documents for data-protection items;
   the exact SecItem category is still unknown.

- `CFTypeID` mappings use native unsigned size and `CFIndex` mappings use native

No query shape, CF type, callback-retention or P/Invoke signature defect was found.
