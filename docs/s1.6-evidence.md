# S1.6 — dynamic public catalogs and book contrast

Date: 2026-08-20. Status: `ACCEPTED / PUBLISHED`.

## User result

- A bounded quick search replaces the APT/BTC-only product constraint. It shows
  at most 40 canonical `BASE/QUOTE` results for the selected product.
- `SPOT` is built from the official credential-free MEXC exchange-info catalog.
- `PERPETUAL` is the union of official Bybit `Trading` USDT
  `LinearPerpetual` pages and active Gate USDT futures contracts.
- One canonical selection controls all cards. A client is created only for an
  exact venue symbol present in the loaded official catalog; unsupported cards
  remain `UNAVAILABLE`. Spot and Perpetual remain isolated.
- APT/USDT stays the preferred default when officially present; APT/BTC buttons
  are shortcuts, not the catalog boundary.
- Search results are bounded; empty, partial, error and stale catalog states are
  explicit. Catalog evidence older than 15 minutes blocks a new selection.

## Exact metadata boundary

- Bybit uses official `symbol`, `baseCoin`, `quoteCoin`, `contractType`,
  `status`, `settleCoin`, `tickSize` and paginated `nextPageCursor`.
- Gate uses exact `name`, `in_delisting`, `order_price_round` and
  `quanto_multiplier` from the USDT contracts catalog.
- MEXC uses exact `symbol`, `baseAsset`, `quoteAsset`, online `status` and
  `isSpotTradingAllowed`. `quotePrecision` is explicitly not treated as an
  official tick; the catalog tick is null and the live-level scale fallback is
  used. No order filter or private-trading capability is inferred.
- No symbol, venue availability, multiplier or trading filter is synthesized.
