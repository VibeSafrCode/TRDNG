# TRDNG Stage 1 — S1.3 evidence

Дата: 2026-08-10. Статус: **IMPLEMENTATION PASS / VISUAL SCREENSHOT BLOCKED**.

## Пользовательский результат

- Один компактный selector переключает только APT/USDT и BTC/USDT.
- Экран явно обозначен как `PERPETUAL`; Spot и Perpetual не смешиваются.
- Выбор является одной canonical selection для всех venue cards.
- Bybit и Gate создают новые Perpetual public clients для выбранного актива.
- MEXC Perpetual показан отдельной карточкой `UNAVAILABLE`; MEXC Spot на этот
  экран не подписывается.
- Карточки используют состояния LIVE / CONNECTING / UNAVAILABLE / STALE.

## Lifecycle и безопасность данных

- Полный VM lifecycle переключения сериализован одним gate.
- До создания нового поколения старые клиенты отписываются, dispose выполняется,
  книги/ликвидность/metadata очищаются атомарно.
- Event handlers и queued Dispatcher callbacks привязаны к generation; callbacks
  старого клиента не могут заполнить новый экран.
- Повторный выбор того же актива не создаёт дубликаты.
- Metadata CancellationTokenSource отменяется и освобождается внутри того же
  сериализованного lifecycle.
- Ошибки initial selection/кликов наблюдаются и отображаются как UNAVAILABLE,
  fire-and-forget metadata имеет безопасный wrapper.
