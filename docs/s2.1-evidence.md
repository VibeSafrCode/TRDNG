# TRDNG Stage 1 — S2.1 evidence

Дата: 2026-08-10. Статус: **IMPLEMENTATION / BUILD / PACKAGE PASS; TEST RUNTIME / VISUAL OPEN**.

## Результат

- `MarketOrderIntent` фиксирует ровно одну venue, canonical instrument/product,
  BUY/SELL, только MARKET, явный sizing mode/value и client order ID. Price у
  MARKET отсутствует; fallback и smart routing отсутствуют.
- BUY preview по умолчанию использует `QuoteNotional` в USDT; SELL —
  `BaseQuantity` в базовом активе. Значение и единица показываются вместе.
- Capability gate разрешает только существующую venue/product запись и блокирует
  `Blocked`/unsupported. MEXC Perpetual остаётся BLOCKED. `NotImplemented`
  допускает только моделирование и никогда не называется готовой торговлей.
- Factory и UI используют одну `DryRunCapabilityPolicy`: `null`, `Blocked` и
  `Unsupported` запрещены; `NotImplemented` — только simulation; `Available` —
  dry-run. Запрещённый результат не создаёт intent и не становится `READY`.
- Validator проверяет положительное decimal-значение, min/max, quantity step и
  требует официальные filters. При их отсутствии возвращается `NeedsMetadata`,
  значения не угадываются.
- Client order ID имеет безопасный ограниченный формат, детерминируемые clock и
  sequence для tests, без секретов.
- UI sizing разбирается строгим parser без group separators и exponent:
  `1,5` и `1.5` означают 1.5; смешанные separators/garbage отклоняются.
- Client ID generator и validator используют одну policy: непустой
  `[a-z0-9-]`, максимум 32 символа и минимум одна буква/цифра. Optional quote-notional step проверяется,
  когда официально задан; отсутствие step не выдумывается.
- До проверки значения validator проверяет coherence metadata: отрицательные
  min/max/step и диапазоны `min > max` возвращают честный `NeedsMetadata` и
  никогда не дают `Valid`.
- При denied venue активная venue/route не меняется, а preview явно называет
  отклонённую и оставшуюся активной площадку.
- UI содержит только preview с крупной маркировкой
  `DRY RUN · ОРДЕР НЕ ОТПРАВЛЯЕТСЯ`; кнопки отправки нет. Видны активная venue,
  product/symbol, BUY/SELL MARKET, значение и единица. Недоступный выбор
  отклоняется без смены активной venue.
