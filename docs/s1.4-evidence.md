## Isolation и lifecycle

- Единый `SelectMarketAsync(baseAsset, product)` сериализует полный lifecycle.
- Monotonic request id реализует latest-request-wins независимо от порядка
  пробуждения semaphore; controller повторно проверяет request id после disposal.
- На switch старые handlers снимаются, clients dispose, книги/metadata/status
  очищаются до создания нового поколения.
- Generation передаётся внутрь каждого snapshot/state/trade callback и проверяется
  до mutation и внутри queued Dispatcher callback.
- Reset Dispatcher post также generation-aware; используется ровно одно увеличение
  поколения на switch.
- Повтор идентичного asset+product не создаёт duplicate clients.

## Детерминированные доказательства в исходниках
